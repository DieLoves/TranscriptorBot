## Препятствие приёмке Mail.ru

`https://cloud.mail.ru/api/v2/dispatcher?api=2` успешно отдаёт HTTPS-сервер
`cloclo*.cloud.mail.ru`. Запрос полного вложенного пути даёт HTTP 301
с назначением `https://cloclo*.datacloudmail.ru/...`.

Пункт 4 спецификации разрешает Mail.ru только HTTPS и `cloud.mail.ru` с его
поддоменами. `datacloudmail.ru` — другой домен, поэтому загрузчик не выполняет
перенаправленный запрос. Запрошен выбор пользователя: сохранить текущую
спецификацию и препятствие приёмке либо явно разрешить новый домен с сохранением
остальных сетевых проверок. До такого решения ограничение не меняется.
