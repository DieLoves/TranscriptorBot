# Handoff

Дата: 2026-10-08. Проект: `/home/dev/workspace/projects/transcriptbot`.

## Objective

Реализовать Telegram-бота транскрипции через Groq по согласованной спецификации v1.
Работать по этапам: после каждого этапа выполнить проверки, создать локальный
коммит и остановиться до дальнейших указаний пользователя. Push и развёртывание
требуют отдельного согласования.

## Current state

- **Этап 1 завершён**; выполнены все доступные проверки проекта.
- Есть пакет `src/transcriptbot`, команды `transcriptbot bot` и
  `transcriptbot worker`, флаг `--check`, загрузка `.env` и валидация настроек.
- Оба процесса пока ожидают сигнал остановки. Polling, SQLite-миграции,
  очередь, загрузчики, транскрипция и доставка ещё не реализованы.

  отдельная сборка официального Bot API и Compose с тремя сервисами.
- Образы запускаются с UID/GID `10001:10001`; Bot API не публикует порт на хост.
  Общие постоянные тома: `data`, `work`, `telegram`. Бот читает `telegram`,
  worker имеет доступ для будущей очистки.
- Локальный `.env` заполнен и проходит новую валидацию. Права `0600`, файл
  исключён из Git. Значения не изменялись и не выводились; ключи через API
  не проверялись. Не запрашивать их повторно.

## Key decisions

- Спецификация: `docs/specs/transcriptbot-v1.md`; план:
  `docs/plans/transcriptbot-v1-implementation.md`. Спецификация не изменена.
- Python 3.12; отдельные процессы бота и одного worker; SQLite/WAL; три сервиса
  Compose, включая официальный локальный Telegram Bot API. Redis и HTTP API нет.
- Python-пакеты зафиксированы в `uv.lock`. Образы Python 3.12.12, uv 0.12.13
  и Deno 2.9.7 закреплены digest; apt использует снимок Debian 2026-10-01.
- Официальный Bot API собирается из `tdlib/telegram-bot-api`, commit
  `e3e9dd8e5b3d7ab8537cd5a10dc31d5ffa8f82d1`, TDLib submodule
  `bc9c263e2bfee06aaab41e82db51a103376030bc`. Автообновлений во время работы нет.
- Установлен `yt-dlp[default]` с локальным EJS 0.8.0; загрузку скриптов во время
  работы не включать. Защищённый транспорт будет реализован в этапе 4.
- Модель фиксирована: `whisper-large-v3-turbo`. Разбиение по паузам без
  перекрытия; после сбоя продолжать с сохранённой части.
- В группах запуск командой ответом или `/transcribe <link>`, проверять
  инициатора, выдавать результат в тот же чат/тему. В личке запуск автоматический.
- Очистка после выдачи включает кеш Bot API. История без содержимого бессрочна;
  файлы после окончательной ошибки — 7 дней. После их удаления продолжение
  недоступно: пользователь отправляет источник заново.
- Соседний CLI использовать как источник алгоритмов и тестов, не как готовый
  backend. Его синхронность, 429, проверка расширений и сборка JSON единственной
  части требуют адаптации. Соседний проект не изменялся.
