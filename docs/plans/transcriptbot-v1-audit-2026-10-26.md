## Подтверждённые проблемы

| # | Проблема | Последствие | Исправление |
|---|---|---|---|
| 1 | `certifi 2026.7.22` (GHSA-6q48-6c7w-9gw2, CRITICAL, 20.10) | Доверие скомпрометированным emSign intermediate: MITM TLS к Groq (API-ключ) и источникам | `certifi` ≥ 2026.10.19 |
| 2 | `brotli 1.2.0` / `brotlicffi 1.2.0.2` (GHSA-9v8h-qqgm-4m35, CRITICAL, 22.10) | OOB write в декодере, библиотека загружается HTTP-клиентами | `brotli 1.2.1`, `brotlicffi 1.2.1.0` |
| 3 | Тест `watch?v=a&list=b` ожидает старый отказ | Полный pytest красный после `ac33476` | Параметр заменён на ссылку плейлиста без `v` |
| 4 | Детерминированное исключение обработчика aiogram не перехватывается | Offset не фиксируется: бесконечный перезапуск бота на одном update | Неожиданная ошибка разбора → `ignored`, логируется только тип |
| 5 | Неожиданное исключение конвейера/загрузки завершает worker | Бесконечный перезапуск на одном задании, очередь стоит | `internal_error`: ограниченные повторы, затем ошибка с «Продолжить»; ошибки SQLite по-прежнему завершают процесс |
| 6 | Файл `*.delivery-<id>.lock` на каждое задание не удаляется | Бессрочный рост файлов в `/data` | Удаление под блокировкой после завершённой очистки терминального задания и разовая уборка сирот при старте |
| 7 | `transcribe` на каждом шаге заново читает и хэширует все прежние ответы | O(n²) чтения JSON/SHA-256 на длинных записях в event loop | Проверка один раз на процесс; сборка и startup-reconcile проверяют всё, как раньше |
| 8 | Без найденной паузы (шум ≥ −42 dBFS) разрез по времени попадал в речь 6/9 | Обрыв слов на стыке | Самый тихий участок окна по энергии 10-мс кадров |
| 9 | Части, начатые посреди фразы, теряли пунктуацию и слова | Хуже текст на стыках | `prompt` из конца предыдущей части, ≤200 байт |

## Проверено без изменений

- Системные пакеты обоих образов против Debian Security Tracker (26.10): 0 исправимых.
- FFmpeg 9.0.2 — последняя версия; Deno 2.9.7 — новых advisories нет.
- Deno запускается yt-dlp без сетевых прав (`--no-remote`, без `--allow-net`).
- SSRF/DNS, redirects, symlink/путь, лимиты, HTML-экранирование, квоты, outbox — без новых дефектов.
